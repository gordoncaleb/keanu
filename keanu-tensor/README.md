# keanu-tensor

Part of [Keanu](https://crates.io/crates/keanu), a probabilistic programming library. Dense row-major tensors of `f64`, `i64` and `bool` with numpy-style broadcasting and slicing, reductions, and linear algebra (via `faer`).

Most users should depend on the [`keanu`](https://crates.io/crates/keanu) facade crate, which re-exports this one.
