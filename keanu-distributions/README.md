# keanu-distributions

Part of [Keanu](https://crates.io/crates/keanu), a probabilistic programming library. Log densities, their gradients, and samplers for the distributions Keanu supports, plus `KeanuRng`.

Most users should depend on the [`keanu`](https://crates.io/crates/keanu) facade crate, which re-exports this one.
