# keanu-io

Part of [Keanu](https://crates.io/crates/keanu), a probabilistic programming library. Save and load Keanu models in Keanu's protobuf format (binary or JSON) and export graphs as Graphviz DOT.

Most users should depend on the [`keanu`](https://crates.io/crates/keanu) facade crate, which re-exports this one.
