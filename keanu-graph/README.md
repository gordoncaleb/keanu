# keanu-graph

Part of [Keanu](https://crates.io/crates/keanu), a probabilistic programming library. Bayesian network graphs: a builder with typed handles, separate state, value propagation, forward and reverse mode auto diff, log probabilities and their gradients, models and sequences.

Most users should depend on the [`keanu`](https://crates.io/crates/keanu) facade crate, which re-exports this one.
